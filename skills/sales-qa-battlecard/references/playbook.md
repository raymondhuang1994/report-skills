# 问答与攻防手册

示例全部虚构：北极星东南亚数据中心基础设施ETF（0000.HK）；F1 管理费 0.99%，同业 F5 为 0.59%，差 0.40 个百分点；F2 前三大 48.6%，有效持股数 11.0 只；F6 同业对同一核心组权重为 33.19%，相对多配 15.41 个百分点，权重日均为 2026-08-29；F3 指数基日 2023-03-01、发布日 2026-03-01，发布前历史为回溯计算；F4 基金 2026-07-01 成立、2026-07-08 上市。核验截点设为 2026-08-31。真实任务必须重建事实库，不复制这些数值；事实统一用 F，计算 R、主张 C、方向 D。

使用前沿用已确认方向与范围。完整工具包执行全部适用检查，指定问题或单个模块只用对应部分；新叙事未确认时先交方向卡并停止，详见 `direction-confirmation.md`。每条答法同时按 `persuasion-workflow.md` 检查证据、机制与边界。

## 1. 问题池的三个来源

| 来源 | 怎么找 | 例句模式 |
|---|---|---|
| 材料的软肋 | 把材料里每个“亮点”反过来问一遍；把每个数字换算成客户视角 | “30 只成分股够分散吗”“0.99% 是不是太贵”“历史业绩是不是回测” |
| 与竞品的差异 | 逐项对比费用、前十大、复制方式、规模、流动性，找出对方占优的项 | “为什么不买便宜的那只”“你们少了什么”“重叠这么高为什么要换” |
| 市场时点 | 上市日前后一个月的行情、周期位置、汇率、上市初期价差 | “现在是不是高位”“汇率怎么办”“刚上市买价差会不会吃亏” |

必答题：费用、集中度、为什么不直接买成分、历史业绩是否回测、现在是不是高位、是不是稳赚、复制或结构风险、为什么包含看似无关的成分、与客户已有持仓的关系、汇率、谁不能买。

## 2. 答法模板

顺序固定：承认事实 → 买到了什么或为什么仍然成立 → 把判断权交还。

| 问 | 口语版（约 60 字，必要条件不删） | 数据行 |
|---|---|---|
| 0.99% 是不是太贵 | 确实贵 0.40 个百分点。是否值得，取决于您是否需要多配核心组；更高费用不会保证更高收益。先比较双方持仓和全成本。 | F1、F2、F5、F6；相对权重差 15.41 个百分点；覆盖测算条件见下节，不把绝对权重当差值 |
| 30 只够分散吗 | 数量不能说明全部：前三大占 48.6%。是否适合作为卫星配置，还要看您已有的持仓和可承受波动。 | F2；有效持股数 11.0 仅描述权重集中度，不等同风险分散效果 |
| 历史业绩是不是回测 | 指数发布前的曲线是回溯计算，基金净值只从实际成立后看。请分别看三段记录，再判断这些历史信息能说明什么。 | F3、F4；指数基日不代表实盘；发布后指数实时记录也不是基金实际净值 |
| 现在是不是高位 | 估值高低需要参照。可以一起看估值分位、盈利假设和您的持有期；这些能帮助判断价格条件，但不保证入场收益。 | 估值与盈利数据带日期；未取得时明确该判断暂不能定量给出 |

不合格的答法：跳过承认（“这个费用在同类里很正常”）；用形容词代替数字（“非常分散”）；替客户判断（“现在就是低位”）。

## 3. 攻防表判定

- 完整表参考 6 到 8 个有效维度；证据不足的维度留在底稿并写补证条件，不进入可用话术。指定少量维度时按范围执行。
- 维度池：核心权重或定位差异、独有部分、地域或范围纯度、入场门槛、费用、结构与复制方式、平台与流动性、历史记录、时区与交易币种。
- “需要先承认的”一列写事实，不写“但是”；例如费用维度写“比同业贵 0.40 个百分点是事实，费用差每年都在，超额不一定每年都有”。
- 费用差换算必须使用相对竞品的权重差。仅在两组合能按同一核心组/其余组拆解，组内收益假设相同、权重静态不变时：相对贡献（百分点）≈ 权重差（百分点）× 两组收益差（百分点）÷100。本例差值为 48.6−33.19＝15.41，覆盖 0.40 个百分点管理费差所需收益差约为 100×0.40÷15.41＝2.60 个百分点；这不是超额收益预测，也未覆盖其他费用、税费与跟踪差异。
- 缺同业权重、分组不一致或存在不同的组内持仓时，不报一个虚假的覆盖值；先取得完整权重/收益分解，或只作费用与持仓分别对照。把 48.6% 直接当相对倾斜、算出约 0.83 个百分点覆盖值是反例。

## 4. 适配矩阵判定

| 判断 | 写法 | 决定性检查（销售当场能做的动作） |
|---|---|---|
| 核心目标客群 | 说清楚现有持仓与本产品的关系 | 穿透现有持仓，看重叠度 |
| 适配 | 写明前提 | 能否接受集中度、波动 |
| 先检验重复 | 已持有主要成分股的客户 | 检查增配后总敞口；如设阈值，写清客户约束或机构规则依据 |
| 优势不充分或匹配度有限 | 有替代方案更合适 | 列出替代方案 |
| 不适合 | 写原因：期限、风险承受、分红需求、流动性 | 直接说明不建议 |

完整矩阵至少两行非适配。虚构示例：“必须定期分配现金：不适合，产品不分红”；“近期有刚性用款、无法承受净值下跌：不适合，权益价格会波动”。上市历史短不能单独证明交易流动性不足；价差、深度和交易安排需另查。

## 5. 一分钟话术与自检清单

一分钟话术约 200 字，按已选方向串起客户问题、资产与产品角色、成立依据、主动讲代价、下一步动作；便利性相关时加入。不承诺收益，不把稀缺说成永久超额利润，不把共性便利说成独有优势。传播标题和研究解释可分两层，但不能靠第二层推翻第一层的误导。

交付前逐项打勾：
- [ ] 已按所选模块交付；完整问答不少于 10 条，指定问题按约定；每条回应关切、解释价值并给边界
- [ ] 攻防表使用有效维度，“需要先承认的”有事实而非空泛转折
- [ ] 完整适配矩阵至少两行非适配；决定性检查可执行，阈值有依据
- [ ] 每个数字带数据日期与编号；同业事实有实际查证日期或仅附件/未查证状态；禁止联网时未越界查证
- [ ] 推荐口径无未经核实的慎用表述；问题、引用、纠错说明中的风险词按语境判断
- [ ] 事实能支持整句主张；比较同口径；日期、相对权重、资本开支/AUM 等推论边界已核对
- [ ] 读者能复述产品角色、主要理由与代价；没有把未证实的原句保留误当推荐
- [ ] 转换类说法加“不构成转换建议”
- [ ] 交付物标“内部讨论稿，未经合规审阅”

完整报告的结构检查可核对问答、攻防和适配表是否齐全；上述推论与表达检查仍需人工/模型逐条判断，结构通过不等于证据支持。
