# 配套 Project 的配置要点（摘要）

技能固定“怎么做”，Project 固定“关于什么”。团队共用一个“管理层深度报告”Project 即可；单份报告体量很大、材料很多时，再另开子项目。

**项目指令（可直接粘贴）**
> 本项目用于撰写交付管理层、董事会、产品委员会与销售团队的中文深度报告。请使用 exec-deep-report 技能，并遵守其中的团队默认约定：先方案后执行、立项三问、两步交付、先独立后融合、不确定先问、删改须逐项确认。知识库中的范例报告只作写法与水准的参照，观点须独立形成；知识库中的公司口径文件（产品清单、官方费率、对外表述禁区）优先于网络信息。知识库里没有的内部事实，请留空并列入数据缺口，不要推测。

**知识库建议放**：管理层认可的范例报告一到三份；已交付的优秀终稿；公司产品清单与官方费率口径；合规慎用词与对外表述要求；常用数据代码表。
**不要放**：过程稿与旧版本；未脱敏的客户数据；会过期的行情数据。
**维护**：每份报告交付后做一次复盘回写，把新踩的坑与新模板提给技能维护人，更新技能版本。
